I checked the live Decisions API docs and they match what the skill describes. Here's how I'd set it up.

## Summary

| Need | Question type | Requests |
|---|---|---|
| Is it spam? | `noul` | **1 request per review**, holding all three questions |
| Which of the 6 categories? | `choice` (6 options) | (same request) |
| How angry, 1–5? | `score` (5 levels) | (same request) |
| Best of 40 items for a query | `choice` with 40 options, plus `no_match` | **1 request per query** |

**Reviews:** all three questions look at the same review and none depends on another's answer, so send them together. Don't wait for the spam result before asking the other two. Output is free and you pay for the input once, so asking all three costs about the same as asking one. Your code simply ignores the category and anger answers when it decides a review is spam.

**Search:** use one `choice` question with the catalogue items as options. Don't ask 40 separate yes/no questions or score each item. The `choice` returns a probability for every item, so you also get a ranking for free. Search queries and reviews have different `state`s, so they can't share a request.

**Check first:** if each review is already linked to a product in your catalogue, look up the category in your database instead of asking the model. Only ask when the product is unknown or the category is unreliable.

## When to trust the answer

Don't pick thresholds by guessing. The docs' examples treat a `choice` confidence below 0.6 as unsure and a `noul` of 0.5 or more as yes, but those are only starting points. To set real thresholds:

1. Label a few hundred reviews and queries yourself.
2. Run them through SubQ and save the raw probabilities.
3. Choose cutoffs separately for each question, based on how bad each kind of mistake is for you.

Rules for each question:

- **`is_spam`:** use two cutoffs, with a review band in between. For example:
  - `noul` ≥ high cutoff → drop automatically.
  - `noul` ≤ low cutoff → accept.
  - Anything between → a person checks it.

  Hiding a real angry review is usually worse than letting some spam through, so set the high cutoff for high precision.
- **`category`:** trust it when `confidence` is above your cutoff. Also check the gap between the top two `probabilities`. A 0.45 vs 0.40 split between kitchen and other is a coin toss. Send predictions of `other` to review, or count them as a signal to improve your category descriptions.
- **`anger`:** `score` is a probability-weighted average, so a value like 3.4 is normal. Round it or bucket it in code. Look at the spread too: if the `probabilities` are split between distant levels (say, most weight on both 2 and 5), the average is misleading. Use low `confidence` or a split like that to flag the review for review. If you only act on high anger (e.g. escalate at 4 or above), tune that one cutoff for good recall.
- **`best_item`:**
  - High confidence on one SKU → return it.
  - Low confidence, or a small gap between the top two → show the top 3–5 items ranked by `probabilities` instead of a single answer.
  - `no_match` wins → fall back to keyword search.

  With 40 options, confidence will usually be lower than for the 6-category question, so its cutoff will be lower too.

Also:

- **Store the full answer** (every probability, not just the winner) so you can change thresholds later without running everything again.
- **Re-check accuracy on a fresh sample every so often.** Outputs can vary between requests, and the model is in public preview, so its behaviour may change.
- **Check what data is retained** before sending review text that contains customers' personal details: https://docs.subq.ai/markdown/using-the-api/data-retention.md

## Cost and operations

- **Price:** $0.05 per 1M input tokens. A review request is a few hundred tokens, so it costs a fraction of a cent. A search request is mostly the 40 item descriptions. At around 5K tokens that's roughly $0.00025 per query. Measure the real figure from `usage.input_tokens` before you scale up.
- **Key:** read it from the `SUBQ_API_KEY` environment variable on the server.
- **Retries:** retry `429` and `5xx` errors with backoff. Fix `400` and `422` errors instead of retrying them.

## Recommended design

| Need | Question type | Why |
|---|---|---|
| Spam | **Binary** (yes/no) | Cleanest signal and easiest to set a threshold on |
| Category | **Single-choice**, 6 options | Exactly one answer from a closed set. Keep "other" as an explicit choice |
| Anger | **Rating / ordinal scale**, 1–5 with a label for each point | Labels make answers consistent; without them, "3" means different things to different answerers |
| Best item of 40 | **Single-choice, staged** (see below) | 40 options is probably over any option limit, and accuracy drops as the list grows |

**Requests per review:** 1 if SubQ allows several questions in one request, otherwise 3. Run the spam question first. If you skip category and anger for spam, the average falls below 3.

**Requests per search query:** use one of these two:
- **Shortlist then pick (recommended): 1 request.** Use cheap retrieval (embeddings or BM25 over title + description) to get the top 8, then ask one single-choice question with those 8 plus "none of these".
- **Tournament (no retrieval): 6 requests.** Split the 40 items into 5 groups of 8, pick a winner from each group, then pick the best of the 5 winners. Shuffle the order inside each group.

## Deciding when to trust an answer
1. **Use SubQ's own confidence signal if it has one.** Set thresholds per question from a labelled sample; don't guess them.
2. **Otherwise, measure agreement.** Ask the same question 3 times (shuffling option order for choice questions) and accept the answer only if at least 2 of 3 agree. For anger, accept if the answers span ≤1 point and use the median.
3. **Calibrate on 100–200 reviews and queries you've labelled yourself.** Choose thresholds that hit your target precision. Spam false positives cost more, so give spam a stricter bar.
4. **Send anything below threshold to a human or an "unsure" queue.** Don't silently force a label.
5. **Item matching:** if "none of these" wins, or the shortlist and tournament results disagree, flag the query. Your catalogue may not contain a good match.

class SnapError(Exception):
    def __init__(self, status: int | None, error_type: str, message: str) -> None:
        super().__init__(f"{status} {error_type}: {message}")
        self.status = status
        self.error_type = error_type


# Errors that no other ticket can recover from either: stop the whole run.
FATAL_STATUSES = {401, 402, 403}


def decide(state, questions, *, attempts=5, timeout_s=60.0, base_delay_s=1.0, max_delay_s=30.0) -> dict:
    """One Decisions request with bounded retries on 429 / 5xx / network errors."""
    key = os.environ.get("SUBQ_API_KEY")
    if not key:
        raise SnapError(None, "no_key", "SUBQ_API_KEY is not set")
    data = json.dumps({"model": MODEL, "state": state, "questions": questions}).encode()
    headers = {"Authorization": f"Bearer {key}", "Content-Type": "application/json"}

    for attempt in range(attempts):
        try:
            req = urllib.request.Request(URL, data=data, headers=headers, method="POST")
            with urllib.request.urlopen(req, timeout=timeout_s) as r:
                return json.load(r)
        except urllib.error.HTTPError as e:
            detail = _error_detail(e)
            retryable = e.code == 429 or e.code >= 500
            if not retryable or attempt == attempts - 1:
                raise SnapError(e.code, detail.get("error_type", "http_error"), detail.get("message", "")) from e
            delay = _retry_after(e)
        except (urllib.error.URLError, TimeoutError, ConnectionError) as e:
            # Timeout or network failure: outcome unknown, but decisions have no side effects, so retry.
            if attempt == attempts - 1:
                raise SnapError(None, "network", str(e)) from e
            delay = None
        if delay is None:
            delay = random.uniform(0, min(max_delay_s, base_delay_s * 2**attempt))  # full jitter
        time.sleep(min(delay, max_delay_s))
    raise AssertionError("unreachable")


def _error_detail(e: urllib.error.HTTPError) -> dict:
    # SubQ errors look like {"detail": {"error_type": ..., "message": ...}}.
    try:
        payload = json.load(e)
    except ValueError:
        return {"error_type": "http_error", "message": ""}
    detail = payload.get("detail") if isinstance(payload, dict) else None
    return detail if isinstance(detail, dict) else {"error_type": "http_error", "message": str(payload)[:200]}


def _retry_after(e: urllib.error.HTTPError) -> float | None:
    value = e.headers.get("Retry-After") if e.headers else None
    try:
        return float(value) if value is not None else None
    except ValueError:
        return None


def _argmax(probabilities) -> tuple[object, float]:
    """Most likely option from a {option: p} dict or a [p, ...] list."""
    if isinstance(probabilities, dict):
        k = max(probabilities, key=probabilities.get)
        return k, probabilities[k]
    i = max(range(len(probabilities)), key=probabilities.__getitem__)
    return i, probabilities[i]


def _severity_level(answer: dict) -> str:
    """Map the score answer to low/medium/high using its most likely level."""
    key, _ = _argmax(answer["probabilities"])
    if isinstance(key, int):
        return SEVERITY_LEVELS[key]
    # Dict keyed by level index or by label: resolve both.
    if str(key).isdigit() and int(key) < len(SEVERITY_LEVELS):
        return SEVERITY_LEVELS[int(key)]
    label = answer.get("legend", {}).get(key, key) if isinstance(answer.get("legend"), dict) else key
    for level, criterion in zip(SEVERITY_LEVELS, QUESTIONS["severity"]["criteria"]):
        if label == criterion or str(label).lower().startswith(level):
            return level
    return str(label)


def triage(ticket: dict) -> dict:
    result = {"id": ticket["id"], "needs_review": False, "review_reasons": []}
    try:
        response = decide({"ticket_text": ticket["text"]}, QUESTIONS)
    except SnapError as e:
        if e.status in FATAL_STATUSES or e.error_type == "no_key":
            raise
        # 400 / 422 / exhausted retries: no decision for this ticket, send it to a person.
        result.update(needs_review=True, review_reasons=[f"api_error: {e}"])
        return result

    a = response["answers"]
    reasons = result["review_reasons"]

    p_urgent = a["urgent"]["noul"]
    if p_urgent >= URGENT_YES:
        urgent = True
    elif p_urgent <= URGENT_NO:
        urgent = False
    else:
        urgent = None
        reasons.append(f"urgent uncertain (p={p_urgent:.2f})")

    team = a["team"]["choice"]
    if a["team"]["confidence"] < TEAM_MIN_CONFIDENCE:
        reasons.append(f"team uncertain (confidence={a['team']['confidence']:.2f})")
    if team == "other":
        reasons.append("team is 'other'")

    severity = _severity_level(a["severity"])
    if a["severity"]["confidence"] < SEVERITY_MIN_CONFIDENCE:
        reasons.append(f"severity uncertain (confidence={a['severity']['confidence']:.2f})")

    # Costly-mistake rule: a high-severity ticket the model does not call urgent gets a second look.
    if severity == "high" and urgent is False:
        reasons.append("high severity but not urgent")

    result.update(
        urgent=urgent,
        team=team,
        severity=severity,
        needs_review=bool(reasons),
        raw={
            "urgent_p": p_urgent,
            "team": a["team"],
            "severity": a["severity"],
            "input_tokens": response.get("usage", {}).get("input_tokens"),
        },
    )
    return result


def read_tickets(path: str) -> list[dict]:
    tickets = []
    with open(path, encoding="utf-8") as f:
        for n, line in enumerate(f, 1):
            line = line.strip()
            if not line:

            try:

def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("tickets", help="JSON Lines file with {id, text} per line")
    parser.add_argument("--workers", type=int, default=4, help="parallel requests (default 4)")

class FatalAPIError(Exception):
    pass


class TicketAPIError(Exception):
    pass


def call_snap(api_key, ticket_text):
    body = json.dumps({"model": MODEL, "state": ticket_text, "questions": QUESTIONS}).encode()
    headers = {"Authorization": f"Bearer {api_key}", "Content-Type": "application/json"}

    for attempt in range(MAX_RETRIES + 1):
        req = urllib.request.Request(API_URL, data=body, headers=headers, method="POST")
        try:
            with urllib.request.urlopen(req, timeout=TIMEOUT_S) as resp:
                return json.load(resp)
        except urllib.error.HTTPError as e:
            detail = _error_detail(e)
            if e.code in FATAL:
                raise FatalAPIError(f"HTTP {e.code}: {detail}") from e
            if e.code not in RETRYABLE or attempt == MAX_RETRIES:
                raise TicketAPIError(f"HTTP {e.code}: {detail}") from e
            delay = _retry_after(e) or _backoff(attempt)
        except (urllib.error.URLError, TimeoutError, ConnectionError) as e:
            if attempt == MAX_RETRIES:
                raise TicketAPIError(f"network error: {e}") from e
            delay = _backoff(attempt)
        print(f"retrying in {delay:.1f}s (attempt {attempt + 1}/{MAX_RETRIES})", file=sys.stderr)
        time.sleep(delay)


def _error_detail(e):
    try:
        detail = json.load(e).get("detail", {})
        return f"{detail.get('error_type')}: {detail.get('message')}"
    except Exception:
        return e.reason


def _retry_after(e):
    try:
        return min(float(e.headers.get("Retry-After")), 60.0)
    except (TypeError, ValueError):
        return None


def _backoff(attempt):
    return min(2 ** attempt, 30) * (0.5 + random.random())


def interpret(answers):
    reasons = []

    p_urgent = answers["urgent"]["noul"]
    if URGENT_BAND[0] <= p_urgent <= URGENT_BAND[1]:
        reasons.append(f"urgency unclear (p={p_urgent:.2f})")

    team = answers["team"]
    if team["confidence"] < MIN_TEAM_CONFIDENCE:
        reasons.append(f"team unclear ({team['choice']}, confidence={team['confidence']:.2f})")
    if team["choice"] == "other":
        reasons.append("no matching team")

    sev = answers["severity"]
    level = max(0, min(len(SEVERITY_LEVELS) - 1, round(sev["score"])))
    if sev["confidence"] < MIN_SEVERITY_CONFIDENCE:
        reasons.append(f"severity unclear (score={sev['score']:.2f}, confidence={sev['confidence']:.2f})")

    return {
        "urgent": p_urgent >= 0.5,
        "urgent_probability": round(p_urgent, 3),
        "team": team["choice"],
        "team_confidence": round(team["confidence"], 3),
        "severity": SEVERITY_LEVELS[level],
        "severity_score": round(sev["score"], 3),
        "severity_confidence": round(sev["confidence"], 3),
        "needs_human": bool(reasons),
        "review_reasons": reasons,
    }


def load_tickets(path):
    with open(path, encoding="utf-8") as f:
        for n, line in enumerate(f, 1):
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
                if isinstance(obj, dict) and "text" in obj:
                    yield obj.get("id", n), obj["text"]
                    continue
            except json.JSONDecodeError:
                pass
            yield n, line


def main():
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("tickets", help="JSONL ({id, text}) or plain text, one ticket per line")
    args = parser.parse_args()

    api_key = os.environ.get("SUBQ_API_KEY")
    if not api_key:
        sys.exit("SUBQ_API_KEY is not set")

    flagged = total = 0
    for ticket_id, text in load_tickets(args.tickets):
        total += 1
        try:
            result = interpret(call_snap(api_key, text)["answers"])
        except FatalAPIError as e:
            sys.exit(f"aborting at ticket {ticket_id}: {e}")
        except TicketAPIError as e:
            result = {"needs_human": True, "review_reasons": [f"API error: {e}"]}
        except (KeyError, TypeError, ValueError) as e:
            result = {"needs_human": True, "review_reasons": [f"unexpected response: {e!r}"]}
        flagged += result["needs_human"]
        print(json.dumps({"id": ticket_id, **result}), flush=True)

    print(f"{total} tickets, {flagged} flagged for human review", file=sys.stderr)


if __name__ == "__main__":
    main()
